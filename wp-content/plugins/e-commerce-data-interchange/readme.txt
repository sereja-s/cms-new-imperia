Бесплатный плагин для автоматической синхронизации товаров, остатков и заказов между WooCommerce и 1С. Работает на любом хостинге, без сложной настройки.


== Description ==

Плагин **EDI - Обмен данными между WooCommerce и 1С** автоматизирует обмен данными между [WooCommerce](https://wordpress.org/plugins/woocommerce/) и [1С](https://v8.1c.ru/), поддерживает формат CommerceML и не требует доработок 1С.

= Почему выбирают EDI - Обмен данными между WooCommerce и 1С? =
- Плагин абсолютно бесплатный, без какого-либо ограничения по функциональности.
- Работает с 1С:Управление торговлей, 1С:Управление нашей фирмой, 1С:Розница, 1С:Комплексная автоматизация.
- Поддерживает полную и частичную синхронизацию.
- Работает на любом хостинге, экономно расходует CPU и RAM.
- Готов к использованию сразу после установки.

= Сайт плагина и быстрая настройка =
Заказать услугу профессиональной настройки синхронизации можно на официальном сайте [https://ediplugin.org/](https://ediplugin.org/?utm_source=wordpress.org&utm_medium=referral&utm_campaign=plugin_listing).

= Основные возможности =
- Синхронизация каталога: товары и вариации, категории, атрибуты и значения, изображения, цены и остатки.
- Двусторонний обмен заказами: синхронизация сайт ↔ 1С, включая статусы и изменения состава заказа.
- Индикация прогресс выполнения обмена.
- Нетребовательный к хостингу: отсутствие специальных требований, стабильная работа на shared-хостинге.

= WP-CLI команды =
После активации плагина доступны команды WP‑CLI:
- `wp edi checkauth` - проверка авторизации узла обмена.
- `wp edi init` - инициализация обмена.
- `wp edi import filename.xml` - импорт данных из XML.


== Installation ==
Заказать услугу профессиональной настройки синхронизации можно на официальном сайте [https://ediplugin.org/](https://ediplugin.org/?utm_source=wordpress.org&utm_medium=referral&utm_campaign=plugin_listing).

= Автоматическая установка =
1. Перейдите в админку WordPress → Плагины → Добавить новый.
2. Введите в поле поиска «EDI» и установите плагин.
3. Нажмите «Активировать».

= Ручная установка =
1. Скачайте архив плагина.
2. Загрузите папку плагина в каталог `/wp-content/plugins/` через FTP/SSH.
3. Активируйте плагин через меню «Плагины» в админке.


== Frequently Asked Questions ==
= Какие требования к хостингу для работы плагина? =
Специальных требований нет. Плагин стабильно работает на shared‑хостинге, экономно расходует CPU и RAM.
= С какими версиями 1С и форматом обмена плагин совместим? =
Совместим с конфигурациями 1С, поддерживающими CommerceML. Нестандартные доработки требуют отдельной проверки.
= Какие данные по товарам передаются? =
Товары и вариации, категории, атрибуты и значения, описания, изображения, цены и остатки.
= Можно ли выполнять двусторонний обмен заказами? =
Да. Плагин синхронизирует заказы сайт ↔ 1С, включая статусы и изменения состава заказа.
= Есть ли индикация процесса? =
Да. Есть индикация процесса выполнения, возможность прервать процесс.
= Как выполняется первая синхронизация? =
Первая загрузка - полная. Дальше возможны инкрементальные обмены только изменившимися данными.
= Нужно ли настраивать обмен на тестовом сайте? =
Рекомендуется начать с тестового сайта, проверить корректность обмена и только потом запускать на живом сайте.
= Где найти документацию и помощь? =
Полную информацию о плагине можно найти на официальном сайте [https://ediplugin.org/](https://ediplugin.org/?utm_source=wordpress.org&utm_medium=referral&utm_campaign=plugin_listing).
