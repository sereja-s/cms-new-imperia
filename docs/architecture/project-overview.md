# Imperia

## Назначение проекта

Интернет-магазин на WordPress и WooCommerce.

Проект создаётся как долгосрочная платформа с упором на:

- высокую производительность;
- минимальное количество плагинов;
- собственный код вместо универсальных тяжёлых решений;
- простоту поддержки;
- предсказуемую архитектуру.

---

## Основной стек

CMS:
WordPress

E-commerce:
WooCommerce

Тема:
Blocksy Free

Собственный функционал:
Плагин Imperia Core

---

## Принципы разработки

1. Бизнес-логика не должна храниться в теме.

2. Основной функционал размещается в Imperia Core.

3. Плагины используются только при реальной необходимости.

4. Каждый новый компонент должен оцениваться с точки зрения производительности.

5. Предпочтение отдаётся собственному коду.

6. Код должен быть совместим с современными версиями PHP.

7. Максимально избегать зависимости от jQuery.
