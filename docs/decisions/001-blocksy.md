# Решение 001

Название:
Использование темы Blocksy Free

Дата:
2026-06-09

Решение:

В качестве базовой темы используется Blocksy Free.

Причины:

- высокая производительность;
- хорошая интеграция с WooCommerce;
- удобная работа с хуками;
- минимальная зависимость от сторонних библиотек.

Последствия:

При необходимости тема может быть заменена без изменения бизнес-логики проекта.
