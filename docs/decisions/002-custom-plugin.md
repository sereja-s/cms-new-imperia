# Решение 002

Название:
Использование собственного плагина Imperia Core

Дата:
2026-06-09

Решение:

Основная функциональность магазина переносится в отдельный плагин.

Причины:

- независимость от темы;
- удобство поддержки;
- возможность переиспользования кода.

Последствия:

Смена темы не влияет на работу бизнес-логики проекта.
