# Решение 004

Название:
Введение bootstrap архитектуры Imperia Core

Дата:
2026-06-09

Решение:

Плагин переведён на архитектуру с централизованным bootstrap:

- Bootstrap как единая точка запуска
- PSR-4 автозагрузка
- Константы вынесены в отдельный класс
- Модульная система через ModuleManager

Причины:

- масштабируемость
- чистая архитектура
- разделение ответственности
- готовность к росту проекта

Последствия:

Добавление новых функций происходит через модули, а не через хаотичные хуки.
