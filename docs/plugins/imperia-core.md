# Imperia Core

## Назначение

Основной плагин проекта.

Плагин содержит функциональность, которая не должна зависеть от активной темы WordPress.

## Bootstrap архитектура

Плагин использует централизованный bootstrap:

1. imperia-core.php — точка входа
2. Bootstrap — запуск системы
3. Constants — константы проекта
4. Autoloader — загрузка классов
5. ModuleManager — управление модулями

---

## Точка входа

Файл:

imperia-core.php

Назначение:

- защита от прямого доступа;
- подключение автозагрузчика;
- запуск Bootstrap системы.

Порядок запуска:

1. Проверка ABSPATH.
2. Подключение Autoloader.
3. Запуск Bootstrap.
